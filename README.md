# Futuristic Student Portfolio

A responsive personal portfolio starter built with semantic HTML5, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP archive.
2. Open the folder in VS Code.
3. Start `index.html` with VS Code Live Server, or open the file directly in a modern browser.
4. Internet is needed for the hosted Google Fonts; the rest runs locally.
